# MacroFlow Studio

键鼠宏录制与自动化执行工具：把录制或编辑的键鼠操作保存为脚本，用识图 / 文字识别做判断，按工作流组织多个脚本按次数执行。当前版本：1.0.0

## 快速开始

1. 启动 `MacroFlowStudio.exe`。目标软件是游戏时，先点击“选择窗口”绑定（绑定后相对轨迹自动识别为游戏转向）。
2. 按 `F8` 开始录制，`F9` 执行当前脚本，`F12` 随时紧急停止。
3. 录制时主窗口自动隐藏（可改），执行前自动把目标窗口置为前台。
4. 侧边栏“保存配置”可保存录制与执行偏好；设置保存在 EXE 同目录 `app_settings.json`。
5. 侧边栏“启动与备份”可开启单份定时备份、开机自启动、启动到托盘和启动后自动执行指定工作流。

## 启动、备份与日志

- 定时备份间隔使用固定下拉选项：`1h`、`1天`、`1周`。它会扫描已配置的脚本目录并备份到 EXE 同目录 `backups/scripts/`。每个脚本固定对应一个目标文件，每次定时任务只覆盖该文件，不生成多份历史副本；当前已打开脚本会备份编辑器里的最新内容。
- “开机自启动”写入当前 Windows 用户的启动项，不需要为其他用户配置；取消勾选会删除该启动项。
- “启动时最小化到托盘”和“启动时执行工作流”可以同时启用。自动工作流运行结束后仍保持在托盘，双击托盘图标可恢复窗口。
- 运行日志自动写到 `logs/年-月-日/MacroFlow_启动时间_进程号.log`。每次启动使用独立文件，日志页的“打开日志目录”可直接查看。

## 录制

- **智能轨迹识别**：鼠标锁在窗口中央时记录原始相对轨迹（游戏视角转向，高频采样 ≤16 ms）；离开目标窗口后恢复普通桌面坐标（默认间隔 20 ms，可调 10–500 ms）。
- 每次开始录制前自动把目标窗口切换为英语（美国）输入法；F8 新录制自动与已打开脚本分离，保存时创建不重名的新脚本。

## 脚本编辑

“脚本编辑”页支持插入以下动作，双击动作可编辑，按住 Shift/Ctrl 多选：

| 动作 | 说明 |
|---|---|
| 延时 | 等待固定毫秒数 |
| 键盘 / 敲击 | 按下/松开/敲击按键，插入时可按键自动检测 |
| 文本 | 输入文字 |
| 鼠标移动 / 鼠标按键 / 点击 / 连续点击 | 屏幕点选记录坐标，点击可选左/右/中键 |
| 滚轮 | 横向/纵向滚动，指定位置 |
| 识图 | 模板匹配找图（见下） |
| 识别文字 | PaddleOCR 离线识别区域文字（见下） |
| 浮动提醒 / 注释 | 屏幕提示 / 备忘文字 |
| 引用脚本 | 实时读取另一脚本执行（内嵌执行，不跳转） |
| 打开软件 / 关闭软件 | 启动程序（带参数）/ 优雅或强制结束进程 |
| 跳转 | 跳转到目标动作行、脚本开头或脚本结尾 |
| 前置窗口 | 执行前把绑定窗口置前 |
| 特殊模块 | 重新执行工作流 / 结束当前最里层脚本并继续 / 跳到脚本实际最后一行 |
| 模块引用 | 插入已保存的模块对象（见“模块对象”） |

编辑操作：撤销 / 重做、向下复制（支持多选）、从此运行（跳过前面动作直接试运行）、保存后清除撤销历史。

## 识图动作

模板匹配找固定图案，可设置：

- **区域**：全屏 / 绑定窗口 / 自定义区域（按住左键拖框选）
- **阈值**：相似度下限，模板背景会变色时开启“忽略背景”只按笔画匹配
- **超时**：等待超时毫秒数 + 检测间隔，超时后继续 / 跳转指定行 / 停止
- **找到后**：继续 / 点击（识图区域中心或自定义坐标）/ 跳转指定行 / 直接结束当前脚本执行工作流下一项
- **二次识别**：命中后可选另一张模板再次确认
- 目标必须实时可见；检测间隔下限 50 ms。

## 识别文字动作

按**文字内容**判断，与识图互补（识图找固定图案，OCR 读会变化的文字）。引擎为 PaddleOCR（纯离线，中文数字识别准确）。

- 框选识别区域（留空 = 全屏），或绑定目标窗口
- 期望文字按“包含 / 等于”匹配；留空 = 识别到任意文字即命中
- 支持轮询等待与超时后继续 / 跳转 / 停止；结果显示在状态栏与执行小窗

## 模块对象

“模块对象管理”把识别设置保存为可复用的独立对象，分类：**切换 / 工作流全局 / 脚本全局 / 特殊**。

工作流全局与脚本全局允许存在同名、同配置的独立模块，只在触发时机上区分。在“工作流全局”“脚本全局”或“全部模块”列表中右键全局模块，可将其改成另一种全局类型，或复制成另一种全局类型；复制所得模块拥有独立 ID，之后可分别编辑。

- **独立身份**：按 ID 引用而非图片路径，同一张图可建多个不同模块，互不覆盖
- **识别设置**：模板、区域、阈值、持续时长、识别方式（模板图片、识别文字、读取数字或无需识图）
- **成功动作 + 附加代码段**：命中后执行的动作，完成后可继续执行一段附加动作（支持跳转、前置窗口等固定动作）
- **超时代码段**：独立设置“连续未识别”超过时限后执行的动作
- 仓库支持拼音排序、批量加入 / 批量从脚本删除、双击编辑、撤销移除

### 读取数字模块

在“模块对象管理”新建切换模块，把“识别方式”设为“读取数字”并框选数字所在区域。运行时会把 OCR 数字段按屏幕从左到右拼接为整数；例如 `0`、`0`、`7` 会得到数字 `7`。

把该模块插入脚本时，当前引用行会要求设置“比较数字”以及“等于 / 不等于或未读取到”的两路结果。两路均可继续下一行、跳转到稳定行对象或结束当前最里层脚本；“等于”默认跳转，“不等于或未读取到”默认继续下一行。读取到数字后立即比较；未读取到数字时按模块的“阻塞识别 / 未识别时限”重试，非阻塞超时后走失败分支。读取数字仅用于脚本里的切换模块，不进入工作流模块行或批量加入脚本。

## 工作流

“工作流”页按顺序组织多个脚本，每一行（步骤）可设置：

- **脚本**：双击更换
- **执行次数**：剩余次数制（失败或手动停止不扣减，减到 0 显示“次数用完”）；可设 0 或勾选**不计次数**（每轮只执行一次）；配置多次执行时，可勾选**第 2 次及以后从指定行开始**——第 1 次从脚本第 1 行（准备动作只做一次），后续次数直接从选定的动作行进入核心流程，双击次数列设置
- **开始前等待**：执行前等多少毫秒
- **重复间隔**：同一脚本相邻两次执行之间等待时间，默认 1000 ms
- **启用/禁用**：禁用行变灰自动跳过，不扣次数
- **全局模块**：步骤可挂接工作流全局模块

其他操作：单击选中行后可**从选中行运行**；**统一设置参数**一次批量修改次数 / 等待 / 间隔；步骤删除可撤销；脚本文件丢失的行标红并在执行时提示原因；**定时执行**可指定 `YYYY-MM-DD HH:MM:SS` 开始时间（留空立即执行，等待期间程序必须保持运行）。

工作流是普通文件（`workflows` 目录下的 JSON）：**新建**开始一个空白工作流，**打开**选择文件载入，**保存**直接覆盖当前打开的文件（未从文件打开的新工作流会先询问文件名）。界面上显示的就是该文件的内容，不存在“恢复模板 / 删除模板”，修改后保存即生效。

## 全局检测

工作流执行期间，启用的全局模块持续检测（共享同一轮截图，不重复截屏），满足条件即触发：

- **打断与恢复**：触发时暂停当前脚本并保存断点，执行模块的成功动作后自动恢复原脚本
- **点击**：点击识别区域中心或自定义坐标；点击前确保目标窗口在前台
- **重启工作流**：触发后可重新执行整个工作流

## 执行与设置

- **强制专注模式**（默认关）：切换英语输入法 + 系统级键鼠锁定（`BlockInput`），阻止误操作；F12 保留为紧急停止。工作流首次开始时设置一次，全局模块打断与恢复期间持续生效
- **执行前置窗口**：独立开关，执行前自动把目标窗口置前
- **悬浮小窗**：执行 / 录制时置顶小窗（各自独立开关），显示进度与动作日志；通过小窗停止会清理按钮产生的末尾录制事件
- **系统托盘**：点关闭按钮可最小化到托盘继续运行，托盘菜单可恢复窗口或退出
- **快捷键提示音**：录制开始/结束、执行、完成、紧急停止各有不同音调，可测试
- **大漠转向兼容**（默认关）：个别游戏对默认 `SendInput` 相对移动无响应时开启，经本机注册的 32 位大漠插件（`dm.dmsoft`）`MoveR` 转向；插件未注册会直接报错，不静默降级
- **读取当前坐标**：实时显示光标坐标与所在窗口，用于手工填写坐标
- **分辨率适配**：脚本记录录制电脑的虚拟屏幕尺寸，换机执行时自动缩放坐标（旧脚本按 1920×1080 处理）

## 文件目录

程序首次启动在 EXE 同目录创建：

- `scripts`：脚本；`workflows`：工作流；`images`：建议存放识图模板
- `app_settings.json`：全部侧边栏配置与窗口绑定
- `paddle_ocr`（仅打包版）：OCR 引擎（paddle 全家 + 模型），与 EXE 同目录，首次使用“识别文字”时才按需加载，删除后 OCR 不可用

“打开”按钮可读取其他目录的 JSON 脚本；模板图片建议放 `images` 并在识图动作里用相对路径（如 `images\start_button.png`），方便迁移。

## 从源码运行与打包

```powershell
python -m pip install -r requirements.txt
python app.py          # 源码运行
.\build.ps1            # 打包，输出 dist\MacroFlowStudio.exe + dist\paddle_ocr\
```

源码运行需要 Python 3.13 + PaddleOCR 依赖（见 run.bat）；“识别文字”依赖 PaddleOCR 模型目录（`paddle_models`）。

打包版（v1.87.0 起）把 OCR 引擎外置：主程序 `MacroFlowStudio.exe`（约 70 MB，不含 paddle）与 `paddle_ocr` 目录（OCR 引擎、模型与全部运行依赖）同目录发布，整个文件夹一起拷贝即可使用；OCR 第一次使用时才加载，启动更快。v1.87.1 起 `paddle_ocr` 目录包含 paddleocr 所需的全部第三方依赖（colorlog 等），不要再做任何删减。运行后首次升级会自动把旧的 `workflow_templates.json` 恢复模板迁移成 `workflows` 下的工作流文件（旧文件改名为 `workflow_templates.migrated.json` 保留备份）。

## 安全限制

- 轨迹采样间隔不小于 10 ms；识图检测间隔不小于 50 ms；单次录制最多 200,000 个动作
- 停止或异常退出时尽量释放仍处于按下状态的按键和鼠标键
- 请遵守目标软件的服务条款；部分游戏禁止任何形式的宏或自动化

## AI 协作规则

- **DeepSeek** 完成修改后不需要打开软件测试效果：不启动程序、不写 GUI 驱动脚本复现 bug、不做视觉检查、不做打包版冒烟测试。交付验收标准 = `python test_core.py` 全绿 + 构建成功 + `verify_build.py` 通过；bug 修复通过代码阅读和单元测试定位，修改完成后由用户自己运行验证。
- **GPT** 完成修改后按需做视觉与冒烟检查：涉及界面布局、按钮显示等 UI 改动时启动程序实际点开确认；纯逻辑改动可直接交付，打包版 DPI 冒烟测试按需运行。
