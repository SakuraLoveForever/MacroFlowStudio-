# MacroFlow Studio v1.0.0

键鼠宏录制与自动化执行工具：把录制或编辑的键鼠操作保存为脚本，用识图 / 文字识别做判断，按工作流组织多个脚本按次数自动执行。

## 功能特色

- **智能轨迹识别**：鼠标锁定在窗口中央时记录原始相对轨迹（游戏视角转向，高频采样 ≤16 ms），离开窗口自动恢复桌面坐标
- **识图 + 离线 OCR 双引擎**：模板匹配找固定图案，PaddleOCR 读会变化的文字（中文数字识别准确），均支持区域、阈值、超时分支与二次确认
- **模块对象仓库**：识别设置保存为可复用对象（切换 / 全局 / 特殊模块），支持附加与超时代码段、备用识别、读取数字、连续点击
- **工作流编排**：多脚本按次数自动执行，全局模块持续检测、命中触发、断点恢复，支持测试模式与从选中行运行
- **强制专注模式**：系统级输入锁 + 自动英语输入法，停止或异常时自动释放按键
- **日常自动化**：执行小窗、定时备份、开机自启动、启动到托盘、分辨率适配

## 使用

下载 `MacroFlowStudio_v1.0.0_win64.zip`（约 230 MB）解压后运行 `MacroFlowStudio.exe`；`paddle_ocr` 目录（离线 OCR 引擎与模型）必须与 exe 保持在同一目录。

更多功能说明与操作手册见 [README](https://github.com/SakuraLoveForever/MacroFlowStudio-/blob/master/README.md)。
