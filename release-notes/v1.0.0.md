# MacroFlow Studio v1.0.0

首个公开发布版本（合并内部 1.87.1 之后的全部修复，按语义化版本重新编号）。

## 本版更新

- 修复打包版 OCR 运行时缺失 `http.cookies`、`unittest.mock` 等标准库导致“识别文字”报错的问题；构建补全依赖闭包，多次构建结果稳定一致。
- 删除大漠（dm）后台键鼠与后台点击（PostMessage）功能及对应界面与设置项。
- 修复执行小窗滚动时目标游戏窗口失焦的问题。
- 修复相对转向动作变慢的回归：仅目标窗口变化时才执行窗口激活，恢复旧版转向速度。
- 全局检测“持续时长”上限由 60 秒放宽到 10 分钟，长驻提示不再误报。
- 修复脚本按次数重复时“剩余 N 次”日志与跳转行不一致的缺陷。

## 使用

下载 `MacroFlowStudio_v1.0.0_win64.zip` 解压后运行 `MacroFlowStudio.exe`；`paddle_ocr` 目录（离线 OCR 引擎与模型）必须与 exe 保持在同一目录。

功能说明与操作手册见仓库 [README](../README.md)。
