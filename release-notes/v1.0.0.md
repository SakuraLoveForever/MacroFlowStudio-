# MacroFlow Studio v1.0.0

首个公开发布版本。按功能模块梳理：

## 录制与回放

- 智能轨迹识别：鼠标锁定在窗口中央时记录原始相对轨迹（游戏视角转向，高频采样 ≤16 ms），离开窗口恢复普通桌面坐标
- 相对转向回放零额外开销：仅目标窗口变化时才执行窗口激活

## 识别与自动化

- 模板匹配识图 + PaddleOCR 离线文字识别（外置引擎，按需加载）
- 模块对象仓库：切换 / 全局 / 特殊模块，附加与超时代码段、持续延时、备用识别、读取数字

## 工作流

- 多脚本按次数编排、全局模块持续检测、断点恢复、测试模式、从选中行运行

## 稳定性

- 强制专注模式与系统级输入锁，异常时自动释放按键
- 执行小窗不抢占焦点；日志按日期 / 会话落盘；定时备份、开机自启动、启动到托盘

## 使用

下载 `MacroFlowStudio_v1.0.0_win64.zip` 解压后运行 `MacroFlowStudio.exe`；`paddle_ocr` 目录（离线 OCR 引擎与模型）必须与 exe 保持在同一目录。

功能说明与操作手册见仓库 [README](../README.md)。
